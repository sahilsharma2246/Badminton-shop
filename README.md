## 📌 Overview

**Badminton Shop** provides a seamless online shopping experience for badminton gear. It features dynamic product filtering, persistent shopping cart management, user authentication via Firebase, and real-time database updates for inventory tracking.

---

## ✨ Features

- **Dynamic Product Catalog:** Browse badminton gear with real-time stock updates and full mobile/desktop responsiveness.
- **Firebase Authentication:** Secure login, registration, and guest checkout support.
- **Real-Time Data Sync:** Instant updates to cart items, orders, and product availability using Cloud Firestore.
- **Persistent Shopping Cart:** Interactive cart calculations with real-time total updates.
- **Cloud Hosting:** Continuously deployed on Netlify for fast edge delivery.
